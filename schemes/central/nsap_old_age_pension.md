# NSAP Old Age Pension (Indira Gandhi National Old Age Pension Scheme - IGNOAPS)

## Basic Info
- **Jurisdiction:** Central
- **Department:** Ministry of Rural Development
- **Official Portal:** https://nsap.nic.in/
- **Guidelines PDF:** https://nsap.nic.in/guidelines/IGNOAPS_Guidelines.pdf
- **MyScheme/State Portal Page:** https://www.myscheme.gov.in/schemes/ignoa

## Eligibility Rules (Structured)

### Must Have (ALL required)
- [ ] Age 60 years or above
- [ ] Belong to Below Poverty Line (BPL) household
- [ ] Not receiving any other pension (central/state)
- [ ] Indian citizen residing in the state

### Must NOT Have (ANY disqualifies)
- [ ] Already receiving old age pension from any government
- [ ] Receiving widow/disability pension under NSAP
- [ ] Government employee (serving/retired)
- [ ] Income tax payee
- [ ] Owns >2.5 acres irrigated / >5 acres non-irrigated land (varies by state)

### Conditional / State-Specific
- [ ] **Central share:** ₹200/month (age 60-79), ₹500/month (age 80+)
- [ ] **AP (NTR Bharosa):** ₹3,000/month (enhanced, replaces NSAP)
- [ ] **TS (Aasara):** ₹2,016/month (age 60-79), ₹3,016/month (age 80+)
- [ ] BPL identification via SECC 2011 or state BPL list
- [ ] Aadhaar mandatory for DBT

## Required Documents (Exact Names)
1. Aadhaar Card
2. Age Proof (Birth certificate / School certificate / Aadhaar)
3. BPL Card / Ration Card (BPL category)
4. Bank Passbook (first page with IFSC)
5. Passport-size Photo
6. Affidavit (not receiving other pension)

## Application Process
- **Online URL:** Varies by state (AP: navasakam.ap.gov.in, TS: aasara.telangana.gov.in)
- **Offline:** Gram Panchayat / Mandal Office / MeeSeva / CSC
- **Key Form Fields:**
  - Name, Father/Husband Name
  - Date of Birth / Age
  - Aadhaar Number
  - BPL Card/Ration Card Number
  - Bank Account Details
  - Mobile Number
  - Address (Village, Mandal, District)

## Benefit Details
- **Amount (Central):** ₹200/month (age 60-79), ₹500/month (age 80+)
- **Amount (AP - NTR Bharosa):** ₹3,000/month
- **Amount (TS - Aasara):** ₹2,016/month (60-79), ₹3,016/month (80+)
- **Frequency:** Monthly
- **Mode:** DBT to bank account

## FAQ / Edge Cases (for RAG)
- **Q: Age proof not available?** → A: Aadhaar with DOB accepted, else medical certificate from govt hospital
- **Q: Not in BPL list but poor?** → A: Apply for BPL survey at Gram Panchayat
- **Q: Already getting state pension?** → A: Cannot get both NSAP and state pension; choose higher amount
- **Q: Pension stops after death?** → A: Yes, legal heir must report death within 30 days
- **Q: Can apply online?** → A: Some states have portals; check nsap.nic.in for state links

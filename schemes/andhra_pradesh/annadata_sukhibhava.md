# Annadata Sukhibhava (Andhra Pradesh) — Farmer Income Support Scheme
**Replaces: YSR Rythu Bharosa | Current as of TDP Government (June 2024+)**

## Basic Info
- **Jurisdiction:** Andhra Pradesh
- **Department:** Agriculture Department, Govt of AP
- **Official Portal:** https://navasakam.ap.gov.in/ (being updated) / https://ap.gov.in/
- **Guidelines PDF:** Pending — check https://ap.gov.in/ for latest GO
- **MyScheme/State Portal Page:** https://www.myscheme.gov.in/schemes/annadatasukhibhava

## Eligibility Rules (Structured)

### Must Have (ALL required)
- [ ] Farmer family (landholder cultivating land)
- [ ] Resident of Andhra Pradesh
- [ ] Land in Andhra Pradesh (any size)
- [ ] Aadhaar linked to land record (Webland/Bhoomi)

### Must NOT Have (ANY disqualifies)
- [ ] Institutional landholders
- [ ] Income tax payee (last assessment year)
- [ ] Government employee (serving/retired Group A/B)
- [ ] Professional (doctor, engineer, lawyer, CA) registered with professional body
- [ ] Pensioner >₹10,000/month (except Class IV)
- [ ] Constitutional post holders

### Conditional / State-Specific
- [ ] **Benefit:** ₹13,500/year per family (includes PM-KISAN ₹6,000)
- [ ] State share: ₹7,500 + Central PM-KISAN: ₹6,000
- [ ] Paid in 3 installments: Kharif (₹4,500), Rabi (₹4,500), Summer (₹4,500)
- [ ] Tenant farmers eligible with tenancy certificate
- [ ] Land must be seeded in Webland portal
- [ ] **Note:** Scheme guidelines under revision by new government — verify latest GO

## Required Documents (Exact Names)
1. Aadhaar Card
2. Land Record (Webland 1B / Pahani / Adangal)
3. Bank Passbook (first page with IFSC)
4. Mobile Number (linked to Aadhaar)
5. Tenancy Certificate (if tenant farmer)

## Application Process
- **Online URL:** https://navasakam.ap.gov.in/ (Annadata Sukhibhava tab)
- **Offline:** Rythu Bharosa Kendra (RBK) / Agriculture Office / MeeSeva
- **Key Form Fields:**
  - Aadhaar Number
  - Name (as per Aadhaar)
  - Survey Number(s)
  - Extent (acres)
  - Village, Mandal, District
  - Bank Account Details
  - Tenancy Details (if applicable)

## Benefit Details
- **Amount:** ₹13,500 per year per family
- **Breakdown:** ₹7,500 (State) + ₹6,000 (PM-KISAN Central)
- **Frequency:** 3 installments per year (Kharif, Rabi, Summer)
- **Mode:** DBT to bank account

## FAQ / Edge Cases (for RAG)
- **Q: Tenant farmer eligible?** → A: Yes, with registered tenancy certificate from Tahsildar
- **Q: Already getting PM-KISAN?** → A: Automatic top-up to ₹13,500; no separate application if PM-KISAN active
- **Q: Land in multiple districts?** → A: Single application covers all land in AP
- **Q: Woman farmer?** → A: Eligible if cultivating land; name in Webland
- **Q: How to check status?** → A: navasakam.ap.gov.in → Beneficiary Status → enter Aadhaar
- **Q: Is this the same as YSR Rythu Bharosa?** → A: Renamed by TDP government; same benefit structure, new name

# SHG Loan Waiver & Interest Subsidy (Andhra Pradesh)
**Replaces: YSR Aasara | Current as of TDP Government (June 2024+)**

## Basic Info
- **Jurisdiction:** Andhra Pradesh
- **Department:** Society for Elimination of Rural Poverty (SERP) / Women Development
- **Official Portal:** https://serp.ap.gov.in/ / https://ap.gov.in/
- **Guidelines PDF:** Pending — check https://ap.gov.in/ for latest GO
- **MyScheme/State Portal Page:** https://www.myscheme.gov.in/schemes/shgloanwaiver

## Eligibility Rules (Structured)

### Must Have (ALL required)
- [ ] Woman member of Self Help Group (SHG)
- [ ] SHG registered under SERP (VELUGU/IKP)
- [ ] Resident of Andhra Pradesh
- [ ] Outstanding loan from bank (as on cut-off date announced by govt)

### Must NOT Have (ANY disqualifies)
- [ ] Not an active SHG member
- [ ] Loan not from scheduled commercial bank / RRB / cooperative bank
- [ ] Loan taken after cut-off date

### Conditional / State-Specific
- [ ] **Loan Waiver:** Up to ₹1,00,000 per SHG member (crop loans, term loans)
- [ ] **Interest Subsidy:** 4% per annum on fresh loans (Vaddileni Runalu)
- [ ] Implemented in phases as announced by government
- [ ] SHG must be active (regular meetings, savings)
- [ ] **Note:** Scheme guidelines under revision by new government — verify latest GO

## Required Documents (Exact Names)
1. Aadhaar Card
2. SHG Membership ID / Passbook
3. Bank Passbook (loan account)
4. Loan Sanction Letter / Statement
5. Mobile Number

## Application Process
- **Online URL:** https://serp.ap.gov.in/ (SHG Loan Waiver tab)
- **Offline:** Rythu Bharosa Kendra (RBK) / SERP District Office / Bank Branch
- **Key Form Fields:**
  - Aadhaar Number
  - SHG Code / Member ID
  - Bank Name, Branch, Loan Account Number
  - Loan Amount Outstanding
  - Mobile Number

## Benefit Details
- **Loan Waiver:** Up to ₹1,00,000 per member
- **Interest Subsidy:** 4% per annum on new loans (Vaddileni Runalu)
- **Frequency:** One-time waiver + ongoing subsidy
- **Mode:** Direct credit to loan account / DBT to bank

## FAQ / Edge Cases (for RAG)
- **Q: Multiple loans?** → A: Total waiver capped at ₹1 lakh across all loans
- **Q: SHG inactive?** → A: Reactivate SHG through Village Organization (VO)
- **Q: Private money lender loan?** → A: Not covered - only bank loans
- **Q: How to check status?** → A: serp.ap.gov.in → SHG Loan Waiver → enter Aadhaar/SHG ID
- **Q: Is this YSR Aasara?** → A: Renamed/restructured by TDP government; same core benefit
